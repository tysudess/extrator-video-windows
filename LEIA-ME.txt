EXTRATOR DE VÍDEOS — WINDOWS PORTABLE v1.9.16
MODERN UI • TIMELINE PREMIUM • COMPRESSÃO INTELIGENTE

BASE PRESERVADA
Esta versão parte da v1.9.15 TIMELINE PREMIUM. O motor funcional de download, proxy, edição, união e exportação foi preservado; a principal mudança é a nova interface visual e o novo ícone do aplicativo.

NOVA INTERFACE MODERNA
- Navegação lateral fixa: Baixar / Editor Timeline / Proxy.
- Cabeçalho com título da página e status da conexão.
- Tela de download reorganizada em cards.
- Botões maiores e melhor espaçamento para uso com mouse/touchpad.
- Foco visual mais claro, contraste elevado e textos auxiliares.
- Tema escuro roxo/azul/ciano alinhado ao preview aprovado.
- Novo ícone embutido no ExtratorVideos.exe.

DOWNLOAD / YOUTUBE / PROXY
- Download por link.
- YouTube e sites compatíveis com yt-dlp.
- Qualidades 360p, 480p, 720p, 1080p e melhor disponível.
- yt-dlp NIGHTLY e Deno.
- Conexão direta ou proxy.
- Senha do proxy não é gravada.
- Diagnóstico do yt-dlp quando necessário.

EDITOR / TIMELINE PREMIUM
- Timeline unificada para 1 ou mais vídeos.
- Miniaturas reais geradas pelo FFmpeg.
- Linha de reprodução global.
- Cortar no cursor com tesourinha.
- Excluir, duplicar e reordenar trechos.
- Prévia contínua da sequência.
- Zoom da timeline.
- Ajustes ±1s, ±100ms e ±10ms.
- Marcar início/fim com precisão de milissegundos.
- Campos HH:MM:SS.mmm.

EXPORTAÇÃO / COMPRESSÃO
- Resolução Original, 360p, 480p, 720p ou 1080p.
- H.264 / AVC.
- H.265 / HEVC para maior compressão.
- Fallback automático para H.264 quando necessário.
- Áudio AAC.
- Controle opcional de tamanho aproximado.
- Originais preservados.

BUILD LOCAL
Execute build_windows.bat depois de colocar em bin:
- yt-dlp.exe
- ffmpeg.exe
- ffprobe.exe
- deno.exe

BUILD GITHUB ACTIONS
O workflow baixa automaticamente os binários, gera o EXE com o novo ícone, monta o portable e publica o ZIP diretamente em GitHub Releases.

ARQUIVO FINAL
ExtratorVideos-Windows-Portable-v1.9.16-MODERN-UI.zip
